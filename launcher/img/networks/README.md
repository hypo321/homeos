# Network logos

Single-colour SVGs, cropped to their drawn shape, shown white in the hero (CSS filter).
Logos are trademarks of their owners; used here only to name where a show is from.

- Simple Icons (CC0), simple-icons@16.37.0: appletv, channel4, crunchyroll, hbo, hbomax, itvx,
  mubi, nbc, paramountplus, showtime, sky, starz, youtube
- Simple Icons (CC0), simple-icons@9.0.0 (later removed at the brands' request): bbc, hulu, primevideo
- Wikimedia Commons: netflix (Netflix_2015_logo.svg), disneyplus (Disney+_logo.svg)

Matching from SIMKL's network names is in `NETWORK_LOGOS` in js/app.js.
